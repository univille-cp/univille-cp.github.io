A programação competitiva pode ser praticada principalmente nas plataformas Beecrowd, CodeForces e Leetcode.

<!--more-->

### Beecrowd

Plataforma com coleções de problemas para prática de programação. Permite utilizar diversas linguagens de programação.

Os problemas tem diferentes níveis de dificuldades.

### CodeForces

Plataforma voltada para a prática e competição de programação. Nesta plataforma estão os problemas das competições anteriores de diferentes regiões e níveis de competições.



### Leetcode

Plataforma voltada para a prática de programação para entrevista de empregos em big techs. Os problemas são organizados pelo tipo de algoritmo e/ou estruturas de dados necessários para ser resolvidos.
