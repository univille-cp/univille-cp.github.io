Explicação sobre o problema J de 2025.

```python
linha = input()
# 1 3 5 6
# [1, 3, 5, 6]

# Conjunto estrutura de dados
# set
conjunto = {"1","2","3","4"};

lista = linha.split(" ")
for e in lista:
    if e in conjunto:
        conjunto.remove(e)
    
print(len(conjunto))
```
